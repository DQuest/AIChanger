## Русский

Исправление для тех, у кого после обновления экран застревал на «Запускается…».

### Что исправлено

- **Сопряжение больше не истекает.** Android забывает сопряжение с беспроводной отладкой, если ею неделю не
  пользовались, а AIChanger подключается к ней только при запуске службы. Если телефон работал без перезагрузки
  дольше недели, следующий запуск (например, после обновления) не проходил. Теперь AIChanger сам включает настройку
  «Отключить тайм-аут авторизации adb», и сопряжение действует бессрочно.
- **Потерянное сопряжение распознаётся сразу.** Вместо минуты бесполезных попыток приложение открывает шаг
  сопряжения в мастере и объясняет, что произошло.
- **Ошибка больше не прячется за «Запускается…».** Если заменить работающую службу прежней версии не удалось, на
  главном экране видна причина и кнопка «Повторить».

### Если у вас уже висит «Запускается…»

Установите эту версию и откройте AIChanger: он покажет шаг сопряжения. Выполните его заново, как при первой
настройке, — после этого служба обновится сама. Кнопка тем временем продолжает работать на прежней версии.

## English

A fix for those whose screen got stuck on «Запускается…» ("Starting…") after an update.

### What's fixed

- **The pairing no longer expires.** Android forgets a wireless debugging pairing that hasn't been used for a week,
  and AIChanger only connects to it when the service starts. If the phone ran without a reboot for more than a week,
  the next start (after an update, for example) failed. Now AIChanger turns on "Disable adb authorization timeout"
  itself, so the pairing stays valid.
- **A lost pairing is recognized right away.** Instead of a minute of useless retries, the app opens the pairing step
  of the wizard and explains what happened.
- **Errors no longer hide behind «Запускается…» ("Starting…").** If replacing a running service of the previous version failed, the
  main screen shows the reason and a «Повторить» ("Retry") button.

### If «Запускается…» is already stuck for you

Install this version and open AIChanger: it shows the pairing step. Pair again as during the first setup, and the
service updates itself. Meanwhile the button keeps working on the previous version.
