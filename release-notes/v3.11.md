## Русский

### Что нового

- **APK в 8 раз меньше:** около 5 МБ вместо 40. Приложение теперь собирается как release-сборка: неиспользуемый код
  и ресурсы удаляются при сборке.
- **Интерфейс быстрее**, особенно при первом открытии: release-сборка не содержит отладочного режима.
- Подсказка про меню питания на главном экране теперь во всю ширину, как остальные карточки.

### Обновление

Установите поверх прежней версии: подпись та же, удалять приложение и заново выполнять сопряжение не нужно.
Откройте AIChanger, и служба обновится сама.

## English

### What's new

- **An 8× smaller APK:** about 5 MB instead of 40. The app is now built as a release build: unused code and resources
  are removed at build time.
- **A faster UI**, especially on first launch: the release build has no debug mode.
- The power menu tip on the main screen now spans the full width, like the other cards.

### Updating

Install over the previous version: the signature is the same, so there is no need to uninstall or pair again.
Open AIChanger and the service updates itself.
